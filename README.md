# Dilemas Digitais

Projeto educacional sobre **tecnologia, privacidade, consentimento e cidadania digital**.

## 🚀 Funcionalidades

* 🔒 Dilemas sobre privacidade e dados
* 📚 Explicações sobre termos complexos
* 💡 Sistema de soluções interativo
* 🎮 Quiz com 10 perguntas
* 🏆 Sistema de pontuação
* 🧊 Efeitos 3D e holográficos
* ✨ Partículas e animações
* 📱 Design responsivo
* ♿ Recursos básicos de acessibilidade

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* Google Fonts

## 📂 Arquivos

```text
index.html
style.css
script.js
README.md
```

## 🎯 Objetivo

Ajudar as pessoas a compreender melhor os **termos de uso e suas escolhas no ambiente digital**, incentivando decisões mais conscientes.
